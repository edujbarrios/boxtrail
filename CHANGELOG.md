# Changelog

All notable changes to BoxTrail will be documented here.

## 0.1.0 — Initial release

- Added deterministic letterbox geometry for source/target image sizes.
- Added reversible xyxy bounding-box transforms and optional clipping.
- Added inspectable resizing, padding, scales, and JSON-compatible geometry.
- Added validation, standard-library unit tests and package metadata.
- Licensed under AGPL-3.0-only with explicit author notices.
- Added GitHub Actions publishing using PyPI Trusted Publishing (OIDC).
