# Contributing

Thank you for considering a contribution to BoxTrail.

1. Open an issue describing the problem or change before proposing a major new API.
2. Keep the library small, deterministic and dependency-free. Include tests for rounding and bounds behavior.
3. Install locally with `python -m pip install -e .` and run `python -m unittest discover -s tests -v`.
4. Submit a pull request with a focused description and examples.

By submitting contributions, you agree to license those contributions under **AGPL-3.0-only**. Keep existing copyright and attribution notices; identify your own copyright where appropriate. No transfer of copyright to the original author is implied.

Publishing to PyPI, creating automated release/upload workflows, and cutting public releases are reserved for the maintainer's explicit decision.
